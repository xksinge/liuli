# 踩坑记录

只记录会重复遇到、且已有规避办法的问题。按时间倒序追加。

## 2026-11-26

### 任务栏常显时 Dock 多上移 48px

- 现象：任务栏从自动隐藏切到常显，Dock top 1344→1248，比预期多上移一个任务栏高度。
- 原因：`Screen.PrimaryScreen.WorkingArea.Bottom` 已扣除任务栏，`BaseTopY()` 又减了 `Taskbar.VisibleHeight()`。
- 处理：只读 `WorkingArea.Bottom - 8`，不再二次扣；修复后 top=1296。详见 Issue #47。

### `git push` 连接重置

- 现象：`Recv failure: Connection was reset`，偶发超时。
- 处理：等待几秒后重试，通常第 2–3 次成功；不是仓库权限或分支问题。

### `gh issue create` 走 GraphQL 500

- 现象：`gh issue create` 偶发 GraphQL 500，中文正文更容易触发。
- 处理：改用 REST `gh api -X POST repos/<owner>/<repo>/issues --input <json>`；JSON 用 `ConvertTo-Json -Compress` 或文件，正文里的换行用 `` `n ``。

### PowerShell 改 C# 文件把 LF 变 CRLF

- 现象：`Set-Content` 默认编码/换行把整文件变成 CRLF，diff 变成整文件。
- 处理：用 `[System.Text.UTF8Encoding]::new($true)` 写 UTF-8 BOM，并 `.Replace("`r`n","`n")`；改完用 `git diff --stat` 确认不是整文件 diff。

### 构建时 `Liuli.exe` 被预览进程锁住

- 现象：`build.ps1` 复制输出失败，提示文件被占用。
- 处理：先 `Get-Process Liuli`，有残留就 `Stop-Process`；`--preview` 退出后也会短暂占用，等 1–2 秒再构建。

### `--preview` 会改写已提交的预览图

- 现象：每次预览用当前时间重绘 `m1-preview.png` / `m1-preview-pressed.png`，产生无关 diff。
- 处理：提交前 `git status`，对不相关预览执行 `git restore -- docs/screens/v2/...`；只保留本次要留档的新图。

### 控制台中文 mojibake

- 现象：`--selftest` 在 PowerShell 里中文显示为乱码，但键值可读。
- 处理：以 UTF-8 文档为准，不按控制台乱码改源码；需要核对中文时读文件。

### C# 5 编译限制

- 现象：`csc.exe` 不接受字符串插值、`?.`、`nameof`、表达式体成员。
- 处理：用 `string.Format` / 拼接、显式 null 判断、完整属性/方法体；构建脚本固定 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

## 2026-11-25

### 分层窗口挂不上 DWM Mica

- 现象：`WS_EX_LAYERED` + ULW 自绘窗口无法直接使用 DWM Mica。
- 处理：用同源圆角、1px 顶边高光、统一描边模拟玻璃；不要为了 Mica 放弃分层窗口。

### 图标缓存键缺少尺寸

- 现象：不同尺寸共用同一缓存，Dock 大图标被 32px 版本污染。
- 处理：`Icons.Get` 缓存键改为 `path|size|mtime`；大图标走 `SHIL_JUMBO`，失败回退 32px。
