# 踩坑记录

只记录会重复遇到、且已有规避办法的问题。按时间倒序追加。

## 2026-11-27

### 桌面收纳不要做“搬文件”式整理

- 现象：v1 把桌面文件真实移到 `文档\Liuli\<分组>`，会让快捷方式目标、IDE/脚本绝对路径、Office 最近文档、同步盘等外部引用失效。
- 处理：TASK-054 改为 Entry 路径索引：`CollectorItem.Path` 永远指向原文件/文件夹，分组只改 `Group`；同步只增删入口，不调用 `File.Move/Copy/Delete`。拖出面板只给 `DataFormats.FileDrop` + `DragDropEffects.Copy`，不默认移动。
- 取舍：不做多个酷呆式独立盒子，一期先单面板 + 分组标签；二期可复用同一份 `Group` 数据渲染多盒子。

### 收纳刷新用 2 秒 UI 轮询，不引入 FileSystemWatcher 跨线程

- 现象：桌面新增/删除/重命名要求 5 秒内可见；`FileSystemWatcher` 在后台线程触发，直接改 `ShellConfig` 和刷新分层窗口需要额外同步。
- 处理：`CollectorForm` 用 WinForms `Timer(2000)` 在 UI 线程调 `CollectorState.Sync(true)`；69 项目前启动/扫描无慢帧，满足 5 秒验收。后续若桌面项数上千，再评估 watcher + `BeginInvoke`。

### 收纳双击要用 OnMouseDoubleClick，单击只做按压/拖拽起点

- 现象：单击直接打开会让双击触发两次打开；面板同时要支持拖动换组。
- 处理：`OnMouseDown` 只记录 tile 起点，移动超过 8px 进入换组；`OnMouseDoubleClick` 才 `Native.ShellOpen`。拖出面板边界时启动 OLE `DoDragDrop`，只允许 Copy。

### 桌面图标隐藏后，收纳面板 tick 要再压一次

- 现象：Explorer 重启后 `SysListView32` 重新可见，原生图标与收纳面板重复。
- 处理：`CollectorForm.TickScan` 在 `CollectorAutoScan` 时每 2 秒检查 `Native.DesktopIconsVisible()`，若配置要求隐藏则再 `SetDesktopIconsVisible(false)`；不写系统“显示桌面图标”偏好。

## 2026-11-26

### 控制面板桌面图标在 Win11 25H2 不显示

- 现象：写 `HideDesktopIcons\NewStartPanel` 的 `{5399E370-B05B-11D1-9F4B-00C04FD91972}` 在 0/1 间切换，`SysListView32` 项数始终 69；原生 `desk.cpl`“桌面图标设置”预览也没有控制面板。
- 原因：Windows 11 25H2 build 26200 桌面已不绘制该图标，不是注册表键或刷新路径问题；`SHChangeNotify`、Explorer 重启、`ClassicStartMenu` 都无效。
- 处理：保留开关与注册表写入，设置页提示“Win11 25H2 可能看不到图标”，不把它当失败；Win10 1903 未回归。

### 桌面图标运行期隐藏不要用 WM_COMMAND 0x7402

- 现象：v1 `Native.ToggleDesktopIcons` 发 `WM_COMMAND 0x7402` 可切换桌面图标，但它改的是系统显示偏好，不区分“本次运行临时隐藏”。
- 处理：v2 只对 `SHELLDLL_DefView` 下的 `SysListView32` 调 `ShowWindow(SW_HIDE/SW_SHOW)`；启动记录原状态、写 `desktop-icons.runtime` 标记，正常退出恢复。系统图标偏好才写注册表。

### 桌面项数不能靠截图判断

- 现象：Explorer 重启后截图左侧看不到“此电脑”，但 `LVM_GETITEMCOUNT` 返回 70，说明图标在截图区域外或被其他窗口遮挡。
- 处理：验证桌面图标一律用 `SysListView32` 的 `LVM_GETITEMCOUNT` + `IsWindowVisible`，截图只作辅助。

### 原生文件对话框：SetWindowText / BM_CLICK 不触发选中

- 现象：向“选择壁纸”的 Edit 控件 `SetWindowText` 能写入完整路径，但“打开”按钮保持禁用，`BM_CLICK`、Enter、对按钮 `PostMessage` 均不提交。
- 原因：Common Item Dialog 依赖真实编辑框的 `EN_CHANGE`/键盘焦点状态，程序化改文本不会触发按钮启用。
- 处理：真实鼠标点文件名框获得焦点，剪贴板放路径后发真实 `Ctrl+V` + `Enter`；`SetForegroundWindow` 在后台进程常返回 false，不要只靠 SendKeys。UIA 树只暴露部分控件，不能依赖 UIA 找文件名框。

### 压暗重烘后 tone 仍用旧壁纸明暗

- 现象：改 `wallpaperDim` 后玻璃底已重烘，但设置页仍是旧明暗/强调色，日志里重烘与主题应用顺序不明显。
- 原因：`ApplyVisualSettings` 只在重烘前应用主题，`Backdrop.Rebuild` 更新 `Light/Mean/Accent` 后没有第二次 `ApplyTheme`；`LoadTheme` 同样可能先重烘后套主题。
- 处理：`ApplyVisualSettings(true)` 与 `LoadTheme` 都改为 `ApplyTheme → Rebuild → ApplyTheme`；`Backdrop.Rebuild` 日志追加 `dim/mean/light`，可直接核对压暗是否进入平均色。注意设置页浅色背景可能只是预览卡片本身，判断主题应看导航/标题文字与日志 `light`。

### 测试壁纸污染 `wallpaperOrig`，恢复仍回到测试图

- 现象：测试中先手动把系统壁纸换成测试图，再调用 `SetWallpaperImage`，`wallpaperOrig` 记录成测试图；点“恢复系统壁纸”后系统壁纸仍是测试图。
- 原因：`WallpaperOrig` 只捕获“首次换图前”的当前系统壁纸；测试前没先恢复真实原图，捕获到的就是测试态。
- 处理：每轮壁纸测试前先用 `SystemParametersInfo(0x0014)` 恢复 `C:\WINDOWS\web\wallpaper\Windows\img0.jpg`，再启动外壳；验收结束用 `_scratch/shell-before-wallpaper.json` 回滚配置。

### 分层窗口截图：PrintWindow 出黑图

- 现象：设置窗 `PrintWindow` 能拿到完整 900×720；Dock/灵动岛同法只有黑图。
- 原因：Dock/灵动岛用 `UpdateLayeredWindow` 自绘，`PrintWindow` 不合成分层内容。
- 处理：Dock/灵动岛改用主屏 `CopyFromScreen` 后按窗口 rect 裁剪；设置窗仍用 `PrintWindow` 最稳。

### 颜色对话框：PostMessage 点不动色块

- 现象：向 `#32770` 颜色对话框 PostMessage 鼠标消息，选中色/确定均不生效；`SetDlgItemInt(706/707/708)` 也不改变最终结果。
- 原因：Common ColorDialog 在模态循环里按真实鼠标状态取值，不认伪造的窗口消息。
- 处理：用 `SetCursorPos` + `mouse_event` 发真实输入；点基本色块再点“确定”，配置写入 `#FF80FF`。取消路径同样用真实输入回 `#FF80FF` 不变。

### CU 截屏是 PIP 桌面，外壳在主桌面

- 现象：`cu.screenshot()` 看不到刚启动的 `Liuli.exe` 设置窗，但 `EnumWindows` 能拿到 `830,360,1730,1080`。
- 原因：CU 当前桌面是 PIP；`Start-Process` 启动的外壳在主桌面（或另一桌面上下文）。
- 处理：本轮改用 PowerShell `CopyFromScreen` 截主屏、`EnumWindows` 定位窗口并用 `PostMessage`/真实鼠标操作；不要用 CU 截图判断主桌面窗口是否存在。

### 面板“置底”无效：`V2Window` 无条件加 TOPMOST

- 现象：面板 `TopMost=false` 仍压在普通窗口上，ExStyle 始终含 `WS_EX_TOPMOST (0x8)`。
- 原因：`V2Window.CreateParams` 无条件 `cp.ExStyle |= WS_EX_TOPMOST`。
- 处理：改为 `if (TopMost) cp.ExStyle |= WS_EX_TOPMOST`；置底后 `0x08090080`，置顶 `0x08090088`。

### 面板坐标是 body 不是窗口

- 现象：配置 `x/y` 与 `GetWindowRect` 相差 12px，容易误判拖动偏移。
- 原因：面板窗口四周留 12 逻辑像素阴影，配置只存玻璃 body 左上角。
- 处理：写盘/拖动/缩放统一用 body 坐标；窗口 Location = `(X-12,Y-12)`，命中测试按 body 判断。

### 任务栏常显时 Dock 多上移 48px

- 现象：任务栏从自动隐藏切到常显，Dock top 1344→1248，比预期多上移一个任务栏高度。
- 原因：`Screen.PrimaryScreen.WorkingArea.Bottom` 已扣除任务栏，`BaseTopY()` 又减了 `Taskbar.VisibleHeight()`。
- 处理：只读 `WorkingArea.Bottom - 8`，不再二次扣；修复后 top=1296。详见 Issue #47。

### `git push` 连接重置

- 现象：`Recv failure: Connection was reset`，偶发超时。
- 处理：等待几秒后重试，通常第 2–3 次成功；不是仓库权限或分支问题。

### `gh issue create` 走 GraphQL 500

- 现象：`gh issue create` 偶发 GraphQL 500，中文正文更容易触发。
- 处理：改用 REST `gh api -X POST repos/<owner>/<repo>/issues --input <json>`；JSON 用 `ConvertTo-Json -Compress` 或文件，正文里的换行用 `` `n ``。

### PowerShell 改 C# 文件把 LF 变 CRLF

- 现象：`Set-Content` 默认编码/换行把整文件变成 CRLF，diff 变成整文件。
- 处理：用 `[System.Text.UTF8Encoding]::new($true)` 写 UTF-8 BOM，并 `.Replace("`r`n","`n")`；改完用 `git diff --stat` 确认不是整文件 diff。

### 构建时 `Liuli.exe` 被预览进程锁住

- 现象：`build.ps1` 复制输出失败，提示文件被占用。
- 处理：先 `Get-Process Liuli`，有残留就 `Stop-Process`；`--preview` 退出后也会短暂占用，等 1–2 秒再构建。

### `--preview` 会改写已提交的预览图

- 现象：每次预览用当前时间重绘 `m1-preview.png` / `m1-preview-pressed.png`，产生无关 diff。
- 处理：提交前 `git status`，对不相关预览执行 `git restore -- docs/screens/v2/...`；只保留本次要留档的新图。

### 控制台中文 mojibake

- 现象：`--selftest` 在 PowerShell 里中文显示为乱码，但键值可读。
- 处理：以 UTF-8 文档为准，不按控制台乱码改源码；需要核对中文时读文件。

### 设置页主题命名被输入法候选窗干扰

- 现象：`SendKeys("Evening")` 时输入法候选窗抢焦点，最终保存成默认“主题 1”；剪贴板粘贴又会追加到默认名。
- 处理：`CommitName` 前 `ActiveControl = null; Application.DoEvents();` 让原生 TextBox 失焦后再读 `Text`；命名框打开时默认全选，用户直接输入即可替换。直接中文键入尚未复测。

### 设置页改滑杆后“当前主题”徽标不刷新

- 现象：`ApplyVisualSettings` 清空 `ActiveTheme`，但设置页控件仍是改前构建的，“当前”徽标和底部文案停留旧值。
- 处理：设置表单加 180ms `Timer`，滑杆松手/开关切换后重建页面；拖动中与命名中跳过，避免控件被重建。

### 720 高度塞不下 6 个面板/主题行

- 现象：面板行 82px + 头部会越过 680 底部栏；灵动岛三开关也会压到底栏。
- 处理：面板行压到 72/76、主题行 78/84；灵动岛滑杆 64、内容开关 54；6 面板/6 主题在 100% DPI 下刚好落在底栏上方，125% DPI 仍需复测。

### 自动化点击不要拿截图裁剪坐标当客户区坐标

- 现象：从 `CopyFromScreen(800,340)` 的截图读像素，和窗口客户区 `830,360` 差 30/20，点主题“加载”会落到左侧空白。
- 处理：用 `GetWindowRect` 得到窗口原点，`PostMessage(WM_LBUTTONDOWN)` 的 `lParam` 用 `屏幕坐标-窗口原点`；Dock 齿轮在客户区 `x≈512..548`，不是截图里的视觉中心。

### C# 5 编译限制

- 现象：`csc.exe` 不接受字符串插值、`?.`、`nameof`、表达式体成员。
- 处理：用 `string.Format` / 拼接、显式 null 判断、完整属性/方法体；构建脚本固定 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

## 2026-11-25

### 分层窗口挂不上 DWM Mica

- 现象：`WS_EX_LAYERED` + ULW 自绘窗口无法直接使用 DWM Mica。
- 处理：用同源圆角、1px 顶边高光、统一描边模拟玻璃；不要为了 Mica 放弃分层窗口。

### 图标缓存键缺少尺寸

- 现象：不同尺寸共用同一缓存，Dock 大图标被 32px 版本污染。
- 处理：`Icons.Get` 缓存键改为 `path|size|mtime`；大图标走 `SHIL_JUMBO`，失败回退 32px。
